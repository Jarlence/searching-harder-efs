# Frozen benchmark implementation

These files are byte-preserving copies from the research archives. The root `integrity_manifest.json` records each file's source collection and checksum. Restore the complete materials using the root `restore_materials.py` before running analyses; collection-specific protocols and environments are retained in the restored directories.

The adjacent original README describes its own historical implementation stage. The repository root README describes the combined R22, X11c, and X12m release.
