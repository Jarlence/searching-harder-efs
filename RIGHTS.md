# Rights and release status

This is a private repository containing project code, analysis outputs, and research materials. No project-wide open-source software license has been selected. A public release requires a license decision by the relevant rights holders; this document does not grant a new blanket license over the repository.

Third-party data retain their original licenses and attribution requirements. The eight additional UCI data sets were checked against their official repository pages on 2026-10-24; those pages identify the data sets as CC BY 4.0. See `DATA_SOURCES.md` for dataset-level attribution and links. Processed arrays are derived data and retain the applicable upstream conditions. The scientific packages document the transformations and their checksums.

The original R22 collection contains data source descriptions and acquisition/verification scripts rather than original third-party dataset files. Source terms still apply when those scripts retrieve data. Software dependencies also retain their own licenses.

This repository does not redistribute third-party research-paper full texts. It does not declare an external preregistration or assign a publication status to the manuscript.
